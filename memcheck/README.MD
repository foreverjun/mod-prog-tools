## Результаты эксперимента

Эксперимент проводился на Ubuntu 24.04.3 LTS и Windows 10 22H2 19045.6466. Программа выделяла 1024 MiB памяти с помощью `malloc` и последовательно обращалась к ней с шагом 4 KiB. Отслеживался resident set size (количество используемой RAM процесса) по мере обращения к памяти в режимах записи и чтения.

### Режим записи (`w`)

В режиме записи количество используемой памяти, по мере ее заполнения для Windows и Linux практически идентично. Сразу после выделения памяти с помощью malloc количество используемой оперативной памяти минимально. Ее количество растет линейно по мере записи, пока не станет примерно равно количеству выделенной памяти (1028 MiB для Windows, 1025 MiB для Ubuntu).

### Режим чтения (`r`)

В режиме чтения количество используемой памяти, выделенной ОС Windows и Linux отличается. При чтении неинициализированных данных из памяти Windows выделяет страницы в оперативной памяти аналогично записи. Количество используемой оперативной памяти растет линейно по мере чтения из нее, пока не достигает размера выделенной памяти(1028 MiB).

В то же время Ubuntu 24.04 практически не выделяла оперативную память при чтении из неинициализированной памяти. Количество используемой оперативной памяти значительно не менялось и при записи первых 128 MiB составляло 1280 kB, а далее не изменялось и составляло 1408 kB.
